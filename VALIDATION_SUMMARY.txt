12. QUICK START GUIDE
================================================================================

LINUX/macOS:
  1. Clone repo: git clone <url> && cd MCPM
  2. Create venv: python -m venv venv
  3. Activate: source venv/bin/activate
  4. Install: pip install -r requirements.txt
  5. Setup env: cp .env.example .env (edit with your API key)
  6. Setup config: cp config.example.yaml fgd_config.yaml
  7. Run GUI: python gui_main_pro.py

WINDOWS (CMD):
  1. Clone repo: git clone <url> && cd MCPM
  2. Create venv: python -m venv venv
  3. Activate: venv\Scripts\activate.bat
  4. Install: pip install -r requirements.txt
  5. Setup env: copy .env.example .env (edit with your API key)
  6. Setup config: copy config.example.yaml fgd_config.yaml
  7. Run GUI: python gui_main_pro.py

  1. docker-compose up -d
